Accessibility

Accessibility statement

Last updated: 10 August 2026

Novel Insights aims to meet WCAG 2.2 level AA on this website.

Accessibility is not a compliance exercise here. A practice that advises public-sector organisations on how to build systems people can actually use should hold its own website to the same standard.

What has been done

The site is built as plain, semantic HTML. It works without JavaScript, is operable by keyboard, uses proper landmarks and heading structure, and is tested for colour contrast and at 200% zoom. It has also been checked with two independent automated tools — WebAIM's WAVE and Google Lighthouse — both run against the live site, most recently on 10 August 2026, with no errors reported and a 100/100 accessibility score from Lighthouse.

Known limitations

Nothing is currently outstanding. This site has been reviewed against WCAG 2.2 AA success criteria — semantic landmarks, heading structure, colour contrast, keyboard and no-JavaScript operability, list markup and focus visibility — and issues found during that review, including that check, have been corrected. Automated tools only catch part of what matters, though: this site has not yet been tested with real assistive technology in a live session, and a clean automated report is not the same as a confirmed WCAG 2.2 AA conformance claim. Repeating both remains good practice.

Reporting a problem

If you encounter something on this site that you cannot access, please write to hello@novelinsights.com describing the page and the difficulty. I will respond within five business days and will tell you what I intend to do about it.

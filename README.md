# Novel Insights — Static Site (GitHub Pages)

This is a minimal, fast static website suitable for GitHub Pages hosting.
It includes one page (`index.html`) with sections for Home, Services, About, and Contact.

## How to use

1) Create a new **public** repository on GitHub (e.g., `novelinsights.com` or `novel-insights-site`).
2) Upload these files to the root of the repository.
3) In the repo, go to **Settings → Pages**, set **Source** to `Deploy from a branch`, pick the default branch (e.g., `main`) and `/root` folder. Save.
4) After the site is live on `https://<your-username>.github.io/<repo>/`, set your **custom domain** in the same Pages settings (e.g., `novelinsights.com` or `www.novelinsights.com`).
5) At your domain registrar (GoDaddy), point DNS to GitHub Pages (see instructions in the main chat).

## Editing
Open `index.html` to edit content, and `styles.css` to adjust styling.
